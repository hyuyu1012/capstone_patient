(앱을 켜지 않아도) 센서 모니터링 동작
식사 감지 시그널이 true면 식사 완료 처리
식사 감지 시그널이 false면

식사 감지


약 복용 감지

식전 (보호자가 체크를 통해서 시간을 미룰 수 있음 -> 미루면 알람이되더라도 그 내용이 모두 초기화)
1. 연관된 식사 30분전  -> 음성 안내(“지금 약드실 시간입니다”)
2. 30분 동안 약 시그널 체크를 진행하며 도중에 True 체크가 되면 -> 약 먹음
3. 30분 동안 약 체크 도중 시그널 체크 종료 5분전 까지 약 먹지 않았다면 음성 재안내(“악드셨나요?)
4. 결국 30분이 경과됐다면 미복용 처리

식후
식후 모드는 연관된 식사의 완료시점으로부터 30분동안 체크되며
식사 일정이 바뀌거나 환자가 늦게 식사를 하게 되면 식후 모드로 체크된 약 또한 일정이 미뤄지게 된다.

0.연관된 식사가 완료되어야만 로직이 실행된다. 다만 식사 완료 없이 보호자가 임의로 체크는 가능하며, 체크 시 로직은 종료된다.
1. 식사가 완료되면 음성안내(“지금 약 드실 시간입니다”)
2.  30분동안 음성 백그라운드 모니터링
3. 약 시그널이 true가 되면 체크
4. 체크 종료 5분 전까지 약을 복용하지 않았다면, 재안내 음성 (“ 약 드셨나요?”);
5. 5분간 약을 먹지 않았다면 종료
